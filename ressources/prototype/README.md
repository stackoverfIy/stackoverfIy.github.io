# Prototyp-Screenshots

Lege hier die echten Screenshots aus dem CARUSO-Prototyp (dev-Branch) ab.
Sie erscheinen automatisch auf den Lösungs-Flip-Cards (klein) **und** im „Im Prototyp"-Showcase (groß).

Erwartete Dateinamen (genau so):

| Datei                  | Feature              |
|------------------------|----------------------|
| `use-case.png`         | Use-Case-Einstieg    |
| `ask-caruso.png`       | Ask-CARUSO (KI-Suche)|
| `3d-fahrzeug.png`      | 3D-Fahrzeug          |
| `beziehungsgraph.png`  | Beziehungsgraph      |
| `oem-pakete.png`       | OEM-Pakete           |
| `warenkorb.png`        | Warenkorb & Teams    |

Tipp: Möglichst breite, scharfe Screenshots (heller Modus), gern mit etwas Rand.
Fehlt eine Datei, zeigt die Seite automatisch einen Platzhalter mit dem Ablagepfad.
